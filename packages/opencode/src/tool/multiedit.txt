Makes several exact string replacements in one file in a single call. Prefer it over several Edit calls on the same file.

Usage:
- `edits` are applied in order, each to the result of the ones before it.
- All edits apply or none do: if any `oldString` is not found, or matches more than once without `replaceAll`, the file is left unchanged.
- Each edit follows the Edit tool's rules: `oldString` must match the file's current content exactly, including whitespace and indentation, and must differ from `newString`.
- Read the file first unless you already know the exact text of every `oldString` (from a Read, a Grep match, or an earlier edit's output).
- To create a file, give the first edit an empty `oldString` and the whole content as `newString`; later edits apply to that content.
- Use `replaceAll` to change every occurrence of an `oldString`, e.g. to rename a variable.
